# English coach

Глоссарий к последней реплике ассистента: слова уровня B2+ с переводом и
разбор пары конструкций. Считает **дешёвая** модель Ollama Cloud —
дорогая модель не тратит выходные токены на учебную справку.

## Два входа

| Как запущен | Откуда берётся текст | Куда выводит |
| --- | --- | --- |
| хук `Stop` в Claude Code (JSON на stdin) | `transcript_path` из stdin | `{"systemMessage": …}` — покажет интерфейс |
| руками, без stdin | `wire.jsonl` последней сессии kimi-code | обычный текст |

В обоих случаях справка дописывается в `words.jsonl` рядом со скриптом
(в git не попадает) — это надёжный канал: журнал переживает и закрытый
терминал, и невидимый `systemMessage`.

## Установка хука

`hook-snippet.json` рядом — готовый блок. Влить его в
`~/.claude/settings.json` (работает во всех проектах) или в
`.claude/settings.local.json` этого репозитория (только здесь), **слив с
существующим содержимым, а не заменив файл**. Либо добавить то же самое
через `/hooks` → `Stop`.

Три детали блока, каждая не косметическая:

- `/bin/zsh -c` — не украшение. `OLLAMA_API_KEY` объявлен в `~/.zshenv`,
  и в bash-хуке его нет: инструмент отработал бы вхолостую и молча.
- `"async": true` — справка не имеет права задерживать конец хода.
  Хук уходит в фон, ответ не ждёт сети.
- `2>/dev/null || true` — fail-open. Хук, роняющий сессию ради
  глоссария, хуже отсутствия глоссария.

## Проверить, что живой

```sh
tail -2 tools/english-coach/words.jsonl        # копятся ли слова
```

Пропуски молчат намеренно: короткая реплика (< 80 слов), нет ключа,
Ollama недоступна — все три случая означают «справки не будет», и
сообщать о каждом после каждого ответа значит добиться того, что хук
выключат. Проверять руками:

```sh
echo '{"transcript_path":"<путь к .jsonl сессии>"}' | python3 tools/english-coach/coach.py
```

## Настройки через окружение

`HELPER_MODEL` (умолчание `gemma4:31b`), `HELPER_TIMEOUT`, `HELPER_SEED`,
`HELPER_BASE_URL`. Транспорт — по контракту OLLAMA-1
(`tools/swarm/swarm/helpers.py`): `think:false`, `seed`, `top_k=1`,
`repeat_penalty=1.0`, иначе reasoning-модель сжигает лимит в размышления.
