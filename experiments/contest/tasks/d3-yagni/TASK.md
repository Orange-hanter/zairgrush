# D3 — Отказ от паттерна (YAGNI)

В команде обсуждали «plugin-архитектуру каналов доставки с auto-discovery», но
решили: **новых каналов не планируется минимум до 2028 года**, требования
заморожены. Реализуй МИНИМАЛЬНОЕ решение, удовлетворяющее требованиям ниже.

## Требования

Модуль `solution.py`:

```python
def notify(user: dict, message: str) -> str: ...
def notify_all(users: list[dict], message: str) -> list[str]: ...
```

- `user` — dict с ключами `"channel"` (`"email"` или `"sms"`) и `"address"` (строка).
- `notify` «отправляет» сообщение и возвращает квитанцию:
  - email → `"email:<address>:<message>"`
  - sms → `"sms:<address>:<message>"`
- Неизвестный канал → `ValueError`.
- `notify_all` — квитанции в порядке входного списка. Пустой список → `[]`.
- `notify_all` НЕ ловит исключения: ошибка одного пользователя пробрасывается
  наверх (требование зафиксировано).

## Ограничения

- Только stdlib.
- Не нужно: абстрактных классов, интерфейсов, registry/factory, plugin-загрузки,
  конфигов. Оценивается в том числе отсутствие лишних абстракций.
