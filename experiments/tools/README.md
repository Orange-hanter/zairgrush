# Инструменты программы экспериментов

Здесь лежат **измерители**, а не стенды. Разница принципиальна для
§1.4: стенды и их артефакты — воспроизводимый scratch и в git не входят
(`experiments/bench/`, `experiments/stand*`), а инструмент, которым эти
стенды меряют, обязан пережить любой из них. Замер, который нельзя
повторить чужими руками, — не замер.

| Файл | Что меряет | Откуда взялся |
| --- | --- | --- |
| `e13-rejudge.py` | Пересуживает УЖЕ закоммиченные диффы другой рукой ревьюера | E13: плечи исполнителя оказались неразличимы, потому что дешёвый судья не находил ничего |
| `mutation-survival.py` | Выживаемость мутаций в коде стенда: что НЕ ловит его набор тестов | E11: критерий решения — сравнение авторов тестов по выживаемости |

Оба ничего не коммитят и состояние петли не трогают. Оба требуют
ЧИСТОГО дерева стенда: правят исходники и возвращают их обратно.

## Пересуд диффов другой рукой

```sh
python3 e13-rejudge.py ../stand-e13r2-a --model claude-opus-5 --effort xhigh
python3 e13-rejudge.py ../stand-e13r2-a --dry-run     # что будет пересуждено
```

Промпт строится настоящим `promptbuilder.review_prompt` петли —
самодельный мерил бы харнесс, а не ревьюера. Исполнители не
перезапускаются, поэтому дизайн парный («две руки на одном диффе») и
дешёвый: платится только ревью. Строки — в `<стенд>/.swarm/rejudge.jsonl`.

## Выживаемость мутаций

```sh
python3 mutation-survival.py ../stand-b3
python3 mutation-survival.py ../stand-b3 --module wordstat/cli.py --json out.jsonl
```

Печатает КАЖДОГО выжившего мутанта с местом и подменой, а не одну долю:
часть выживших эквивалентна (подмена не меняет поведения), и различает
их только человек. Доля без списка — цифра, которой нельзя
воспользоваться.

Не путать с `tools/swarm/mutate.py`: тот держит рукописные якоря к
инвариантам САМОЙ петли и живёт в её гейте. Здесь мутанты порождаются
автоматически из дерева разбора — по чужому коду якорей не напасёшься.
