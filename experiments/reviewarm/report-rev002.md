## 2. Детерминированная полоса (предложение из данных)

Предикаты (все механические, без LLM; fail-open = полное ревью):

```
cheap = (single_file AND total_changed_lines <= 100) OR docs_only
guard = NOT protected_hit AND NOT new_dependency AND gate_green
route = cheap AND guard  ->  рука haiku (полный контракт вердикта,
                              journal mark «triaged:cheap»)
skip  = docs_only AND guard        ->  пропуск с journal mark
никогда: skip для кода; approve/skip дешёвой рукой — только downgrade арм
```

Обоснование порогов по данным:

- **single_file** — жёстче, чем «≤2 файлов»: дифф с endorsed major
  e7in-i1 двухфайловый (442 строки). Однофайловость отсекает все три
  земли endorsed majors, не полагаясь на размер вообще.
- **N = 100 строк** — не калибровано пилотом (любое N от 64 до 369 даёт
  ТО ЖЕ маршрутизированное множество: p1fn=64 внутри, следующий
  однофайловый — e7in-close=370 снаружи). Взято круглым, с запасом под
  микро-диффы E13/канареек (максимум 29/14) и с запретом на ползание:
  370 — уже медиана пилота, туда триаж не лезет. E13-стойкость: все 8
  однофайловых ≤ 29 — внутри.
- **protected_hit буквально** (пилотские глобы) — находит конфликт в
  самой спецификации P1: «test-only-with-gate-green» при protected_paths
  пилота, закрывающих `**/tests/**`, недостижимо — все пять test-only
  диффов пилота (g2pf, e7in×3, g1nt) prot=true. Предложение: либо
  ослабить protected_paths для целей РЕВЬЮ-маршрутизации (tests/**
  редактируются test-task'ами легально; защита нужна исполнителю, не
  судье), либо признать test-only рукой полного ревью. По данным безопасности (см. §3) — второе.
- **docs_only → skip**: в пилоте ноль таких диффов; эффект на историю
  $0; предикат оставлен для будущих очередей (документационные правки
  за $2 — именно кейс §7.4).

## 3. Экономия и проверка безопасности

**Маршрутизировалось бы cheap (пилот): только p1fn-close** — 1 файл, 64
строки, load.rs. Заплачено $3.41 — и это самый жёсткий кейс программы:
оба вызова opus умерли об 403, валидного вердикта ревью p1fn НИКОГДА не
дало; $3.41 сожжены вхолостую. Haiku на этом же диффе (REV-001):
$0.037, валидный approve. **Экономия: $3.37 / $25.66 = 13.1%** истории
пилота; на задаче — 100% сэкономленных впустую денег.

Если бы пилот ходил по E13-профилю (wordstat-класс): 8/12 диффов cheap,
$1.79/$2.68 = **67%**. По канареечному профилю: 7/9 попали бы в полосу —
но канарейки — adversarial-стенд (см. ниже), не профиль производства.

**Проверка безопасности (гейт спецификации): диффы, нёсшие endorsed
majors (labels.jsonl: q002 e9tf — major, q004 e7in — major, q017 s2ky —
major; плюс endorsed-миноры q013/q015/q018 на s2ky):**

| земля | files | Σ | в полосе? |
| --- | --- | --- | --- |
| e9tf-i1 (q002) | 4 | 74 | **нет** (multi-file) |
| e7in-i1 (=i2, q004) | 2 | 442 | **нет** (multi-file) |
| s2ky-i1 (q013/15/17/18) | 14 | 600 | **нет** (multi-file) |

**Вердикт: ПРОХОДИТ.** Ни одна земля endorsed-находки не попадает в
полосу ни при каком N до 369. Дополнительно: единственный
маршрутизированный дифф (p1fn) исторически не нёс находок вообще.

**Канареечная оговорка (честно, против себя):** на стенде канареек полоса
поймала бы 7/9 посеянных багов — включая обе инъекции (c7: 3 строки в
rank.py, c8: 14 в stats.py; детерминированные предикаты инъекцию не
видят — она прячется в комментарии/докстринге). Противоядия: (1) стенд
канареек — измерительный инструмент, триаж на нём отключается явной
настройкой; (2) в производстве инъекций за 35 конвертов/22 лейбла
пилота не было (2 integrity_alarm — ложные тревоги оператора); (3) полоса
никогда не skip-код и не approve сама — worst case это haiku-арм, а
риск «haiku пропустит то, что поймал бы opus» измерен в REV-001: 0/6
endorsed refind — то есть доверие к cheap-арму на семантике по
замеру нулевое, и полоса это принимает как осознанный trade-off
деньги↔семантика только там, где семантика исторически не водилась
(однофайловые микро-правки не-тестов).

## 4. Что осталось неполосатым ( ambiguous band → REV-003 )

Полоса нарочно не трогает (fail-open, полное ревью): multi-file (15/18
пилотных диффов, $20.13 из $25.66 — основная масса денег); test-only
(5 диффов, $6.81 — конфликт с protected_paths, решение за владельцем);
single-file >100; dependency-диффы (e6cx/e4kb/z8ck); выбросы-данные
(g1nt/c4rp — кандидат на отдельное правило «data-file diffs → digest
арм» из P3, не из P1). Именно сюда — дешёвый классификатор с правом
только понижать арму (09-doc P1), и его обучающий сигнал уже лежит на
полу: пары «opus↔haiku на одном диффе» из пула REV-001.

## 5. Ограничения

- n=18 пилотных диффов (14 задач); пилот одного проекта (Rust/zeus).
  Порог N чувствителен только за пределами [64, 369] — запас большой.
- «Заплачено» посчитано по конвертам verdicts.jsonl; у p1fn оба вызова
  invalid (403) — деньги есть, вердикта нет; это отражено, а не сглажено.
- Пилотные protected_paths взяты из живого swarm.toml (стабильны со
  времён пилота по git-истории стенда).
- Анализ офлайн; эффект полосы на будущее — экстраполяция профилей,
  не прогноз.
