# REV-005 (B8): quote-check фильтр — детерминированный pre-step (NXT-014)

Дата: 2026-09-14. **$0 metered** — офлайн-формализация и сверка по
существующим артефактам REV-004 (ни одного вызова LLM/API; корпус —
`git show` read-only по локальному стенду). Источник: report-rev004.md,
находка (1) вердикта P3 — «механическая проверка цитат работает и дешёва,
фильтр обязателен». Опциональный confirm re-run (~$1.5) отложен за
бюджетным гейтом владельца.

## Что сделано

Ad-hoc проверка цитат из `rev004/digest.py` (`extract_quotes`, `norm`,
`verify_quote`) формализована в переиспользуемый модуль
**`experiments/reviewarm/quote_check.py`** (рядом с `replay.py` /
`analyze.py` / `bakeoff.py` — общий слой reviewarm, куда импортируют
будущие rev*-скрипты). Три уровня на цитату:

| уровень | смысл | доля на корпусе REV-004 |
| --- | --- | ---: |
| L1 extracted | цитата распарсилась в {file, line, quote} (строгий JSON, иначе regex-фолбэк) | 291/316 объектов (~92%) |
| L2 verbatim | нормализованная цитата дословно в корпусе (файл на closing-рефе/HEAD, иначе текст диффа) | 215/291 = **74%** |
| L3 at_line | …и на указанной строке названного файла | 82/291 = **28%** |

Фильтр (поправка 1 REV-004): в промпт идут только L2-прошедшие, список
режется до 15, номера строк помечаются приблизительными, kind →
«evidence», цитаты усечены до 120 символов.

## Воспроизведение семантики (контроль детерминизма)

- **Re-verify по git-дереву** (`--stand ~/work/zeus-pilot`, closing-рефы из
  `digest/<key>.json`): все 291 цитат пересчитаны, расхождений с
  записанными в REV-004 флагами real/at_line — **0**.
- **Побайтовое воспроизводство** `digest/<key>.filtered.txt` через
  `filter_digest` + `render_filtered`: **15/15 файлов идентичны**.
- Расхождение «313 цитат» отчёта REV-004 против 291 в записанных json —
  это L1-потери парсинга: в сырых `.txt` ~316 quote-объектов (все 15
  обёрнуты в ```json-фенсы, поэтому всегда regex-путь), ~25 не
  распарсились (худшие: c4rp 14→8, s2ky-i2 15→10). L1 — отдельный
  уровень фильтра, не шум округления.

## Интеграционная точка (НЕ сделано — граница задачи)

Pre-step относится к контуру, где контент дайджеста/хелперов входит в
промпт ревьюера — в swarm-петле это слой между дешёвым хелпером
(`ollama_chat`-вызовы в `tools/swarm`) и сборкой промпта ревьюера:
любой список цитат от дешёвой модели обязан пройти
`check_quotes → filter_digest → render_filtered` до вставки секции.
В `tools/swarm` в этой задаче ничего не менялось.

## Ограничения

- Re-verify транзитивен к стенду: closing-рефы читаются из живого
  дерева `~/work/zeus-pilot`; смена стенда = смена корпуса (флаги
  REV-004 при этом остаются записанным снимком — режим без `--stand`
  читает их как есть).
- L1-потеря (~25 объектов) оценена по `"line":`-ключам сырых `.txt` —
  это оценка, а не точный счёт (отсюда 316 против «313» в отчёте
  REV-004: один и тот же шум подсчёта).
- Confirm re-run фильтра на свежем дайджест-контуре (~$1.5) отложен —
  бюджетный гейт владельца.
