# ADR-008: гибридная навигация по коду — три инструмента, три роли

Дата: 2026-08-08. Статус: принято. Заменяет решение ADR-007 в части
«ctags не использовать».

## Контекст

ADR-007 отверг ctags по результатам проверки, которая оказалась неверной:
в системе стоял **Exuberant Ctags 5.8 (2009)**, а не universal-ctags.
Выяснилось, что `brew install ctags` ставит именно устаревшую реализацию,
а нужен отдельный конфликтующий пакет `universal-ctags`.

Параллельно обзор ландшафта показал, что у Claude Code есть **родной
LSP** — 13 официальных плагинов Anthropic, включая `pyright-lsp` и
`rust-analyzer-lsp`, причём оба уже включены в настройках этой машины.

Оба факта меняют картину: инструментов больше, чем предполагалось, и
каждый силён в своём.

## Данные

| Инструмент | Что даёт | Чего не даёт | Замер |
| --- | --- | --- | --- |
| universal-ctags 6.2.1 | определения + **импорты**, 164 языка, JSON, `scope`/`roles`/`signature` | вызовы («кто зовёт») | 14 мс на стенде |
| stdlib `ast` + разбор импортов | **точные вызовы** с позициями, квалифицированные символы | только Python | 17 мс, 118 симв., 129 ссылок |
| tree-sitter | парсинг любого языка с грамматикой | разрешение имён (считает по голому имени) | Rust разобран полностью |
| родной LSP (pyright / rust-analyzer) | точные `incomingCalls`, `findReferences`, диагностика | пакетный артефакт для промпта; требует настроенного workspace | `incomingCalls` совпал с ast-индексом |

Ключевая проверка: LSP `incomingCalls` для `clean_token` вернул
`wordstat/stats.py:13 (_word_freq_cached)` — **ровно то же**, что
ast-гибрид. Два независимых метода совпали, значит разрешение импортов в
нашем индексе корректно.

## Решение

**Три инструмента, три непересекающиеся роли:**

1. **Карта и blast radius в промпт** — пакетный артефакт, кладётся в
   handoff: `ast`-индекс для Python, `rust-analyzer --scip` или
   tree-sitter для Rust. Обоснование: агенты stateless, состояние живёт в
   файлах (§3), поэтому контекст должен быть готов **заранее**, а не
   добываться по одному запросу.
2. **Точечные доуточнения по ходу работы** — родной LSP. Реактивный,
   сессионный, отвечает по позиции в файле. Бесплатен (плагин уже есть),
   но требует установленного языкового сервера и корректного корня
   проекта.
3. **Широкий охват языков** — universal-ctags: определения и импорты для
   всего, что есть в репозитории, включая языки без нашего разрешателя.

**Гибридный индекс** склеивает первое и третье, помечая **уровень
достоверности** каждой связи: `resolved` (разрешённый импорт, известен
вызывающий), `import` (известен только импорт), `name-match` (совпадение
по имени). В выводе они идут от точного к приблизительному с подписями
«точно / импорт / по имени».

Это не украшение: агенту нельзя выдавать догадку за факт — на
приблизительной ссылке ревьюер построит finding, а исполнитель правку.
Тот же приём независимо применён в Graphify (пометки `EXTRACTED` против
`INFERRED`).

## Последствия

- (+) Мультиязычность без потери точности: ctags покрывает всё, `ast`
  уточняет Python, tree-sitter добирает языки без разрешателя.
- (+) LSP-ветка бесплатна и уже включена — это подтверждённая замена
  отдельному MCP-серверу навигации, который планировался на этап 2.
- (+) Индекс кросс-проверен независимым инструментом.
- (−) Три зависимости вместо нуля. Смягчено: **все опциональны** —
  `ast`-слой работает всегда, остальные подключаются, если инструмент
  найден (`have_ctags()` отвергает Exuberant по строке версии).
- (−) LSP требует настроенного workspace: без разрешения импортов
  `findReferences` молча возвращает только определение. В петле это
  выполняется (агент запускается с cwd = корень репозитория), но для
  произвольных каталогов — нет.

## Что проверено и отвергнуто

Из обзора ландшафта: `mcp-language-server` (мёртв ~15 месяцев, открыт PR,
чинящий порчу файлов при rename), `gitingest` (год без коммитов),
Sourcetrail (Python-поддержку вырезали), `cased/kit`
(`find_symbol_usages` буквально грепает текст), Glean (сборка только
Linux). `codanna` и `code-graph-rag` — живые и с настоящим резолвингом,
но bus-factor 1; брать как источник идей, не как зависимость.
