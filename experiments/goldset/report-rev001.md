## Что это значит для P0

1. **Haiku на этой земле — «молчаливое одобрение» с тремя оговорками:**
   condense-visibility, посторонний temp-файл, и одно настоящее
   семантическое попадание (e9tf-close, decision-mismatch). Ни одной из
   6 человеко-подтверждённых находок — включая 3 major — не
   повторила. Гипотеза 09-док «re-finds even one endorsed major → 5×
   majors/$» **не подтвердилась**: 0 majors за $1.56.
2. Цена реальна и низкая: $0.09/дифф против $1.28 среднего по opus
   (и sonnet $1.11) — но экономия не конвертируется в находки.
3. Пары «opus↔haiku на одном диффе» из пула всё равно ценны как данные
   (копятся бесплатно в пилотной очереди), но доверять haiku-раунду
   вердикт на основании этого замера нельзя — 0/3 endorsed majors.
   Дешёвой руке вердикт не принадлежит (§5 09-дока) — замер это
   пока подтверждает, а не опровергает.
4. Инфраструктурный урок: executor-стримы ПИЛОТ-1 оказались полной
   записью состояний (Read-снимки до правок + failed-call фильтр +
   cargo fmt реплей) — recall-замер, который 09-doc §4 Step 0 назвал
   невозможным без нового харнесса, сделан впервые; харнесс —
   `experiments/reviewarm/rev001/replay_ground.py`, валидация
   write-tree равенством.

## Ограничения (честно)

- n=18 диффов, одиночный прогон, LLM недетерминирован; g2pf без
  вердикта (таймаут ×2).
- Промпт — снапшот эпохи, не побайтный пер-раундовый; gate_tail
  константный; human_answer из живого tasks.json мог видеть решения,
  которых первоначальный ревьюер не видел (раскрытая асимметрия).
- cwd судов — живой стенд, а не дерево раунда (дифф в промпте
  дословен; инструменты — опциональное чтение).
- s2ky-i1 ground — дерево стэша + реген; сам стэш не валидируется
  write-tree равенством (его состояние не закоммичено). s2ky-i2 и вся
  форвард-цепочка — валидированы.
- endorsed refind ≠ полнота ревью в целом: haiku нашла находки вне
  лейблов (temp-файл, condense) — часть из них вероятно ложнопо-
  ложительны по отношению к пилотной практике (opus их не поднимал).
- Один субъект суждения matching'а (консервативный quote-anchor,
  задокументирован по кейсам).
