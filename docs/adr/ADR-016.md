
# ADR-016: ZCode — третий CLI-движок исполнителя; умолчание остаётся kimi

| Поле | Значение |
|------|----------|
| **Статус** | ✅ accepted |
| **Дата** | 2026-09-11 |
| **Автор** | cursor-grok |

## Контекст

ADR-011 (2026-08-22) сделал движок исполнителя ключом конфига: kimi по умолчанию, claude, ollama как chat-fill. Ревьюер, планировщик и документатор ходят через claude. Умолчание кода не менялось (ADR-002: K3 внутри kimi).

На этой машине 2026-09-11 установлен клиент Z.AI для Mac (ZCode.app). CLI — zcode 0.16.5, бинарь /Applications/ZCode.app/Contents/Resources/glm/zcode.cjs, в PATH часто нет. --help — контракт: --prompt (не stdin), --json (один объект, не NDJSON), --mode yolo, --allowed-tools / --disallowed-tools, --cwd, --surface terminal. Флагов --model, --json-schema, --effort, stream-json нет. Пример справки Bash(git *) слишком широк: закрыл бы git diff.

Модель в рантайме бандла видна как zai/glm-5.1 / zai/glm-4.7; живые веса — ~/.zcode/cli/config.json. zcode login через OAuth ненадёжен.

Нужен третий CLI той же роли исполнителя, не смена ревьюера и не смена умолчания. ADR-011 это не отменяет: список движков расширяется, правило именования и отказ на незнакомом имени остаются.

## Решение

Вариант D. В закрытый список ENGINES / EXECUTOR_ENGINES добавляется zcode. Умолчание кода — kimi (ADR-011, ADR-002). Ревьюер — claude.

Именование прежнее: executor_engine либо префикс executor_model (zcode:glm-5.3 старше ключа). Незнакомое имя отказывает на старте.

Вызов: which(zcode), иначе node + бандл ZCode.app, иначе логическое имя zcode (FileNotFound на спавне; doctor уже отказал, если движок выбран). Argv всегда несёт --prompt, --json, --mode yolo, allow/deny как у claude, --surface terminal; --cwd — путь AgentDriver. --model, --browser-use, --verbose, --json-schema, --effort не кладутся.

Конверт --json: json.loads всего stdout (pretty-print и баннер вокруг скобок допустимы), не parse_claude. Отчёт — parsing.report_in(response). Usage camelCase → tokens_in / tokens_out / cache_read; отсутствующие поля не пишутся; cost_usd только если в конверте реально есть USD.

Doctor проверяет выбранный zcode (zcode version или node bundle version). Невыбранный отсутствующий zcode — опциональная строка, как невыбранный kimi. Если движок zcode и модель задана — doctor говорит, что CLI --model не принимает.

Этот ADR не supersede ADR-011.

## Альтернативы

A) Сменить умолчание исполнителя на zcode. Отвергнуто: ADR-011 и ADR-002 держат «ничего не настроено = kimi» ради сравнимости плеч E8/E10; этот репозиторий на zcode сам не переключается.

B) Гонять GLM через Claude Code с ANTHROPIC_BASE_URL=https://api.z.ai/api/anthropic. Отвергнуто: это другой продукт и чужой argv; ревьюер остаётся claude, смешивать его транспорт с исполнителем нельзя.

C) npm-пакеты zcode / zcode-app-cli или GUI/CDP. Отвергнуто: контракт снят с --help бандла 0.16.5, не с чужой обёртки.

D) Добавить zcode в закрытый список движков, умолчание kimi, ревьюер claude. Принято.

## Последствия

(+) У исполнителя третий CLI: отказ квоты kimi или нежелание класть работу на claude больше не останавливают роль. Префикс zcode:… в executor_model точечно сажает одну задачу плана на ZCode, не трогая прогон.

(+) Git-запись запрещена тем же механическим списком, что у claude (Bash(git commit:*) …), не примером справки Bash(git *), который закрыл бы git diff.

(−) CLI 0.16 не принимает --model: хвост executor_model в метрике и в doctor, живые веса — ~/.zcode/cli/config.json. Смена модели без правки конфига ZCode — ложное ожидание.

(−) --json молчит до финала. Драйвер держит silence_timeout (умолчание 600 с); stderr тоже heartbeat. Короткий таймаут убьёт живой вызов.

(−) cost_usd в захваченном конверте нет — нулевая цена была бы ложью, как у kimi. total_budget_usd исполнителя на zcode не видит. quota_error не расширяли: замерённого текста отказа нет.

(−) zcode login через OAuth на этой машине ненадёжен; рабочий путь — ключ Coding Plan или вход через GUI.

Не сделано и не будет без отдельного решения: ревьюер/планировщик на ZCode, смена умолчания, npm-обёртки, GUI/CDP, выдуманный флаг --model.
