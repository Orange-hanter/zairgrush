
# ADR-019: карта репозитория в handoff исполнителя — когда нужна ориентация

| Поле | Значение |
|------|----------|
| **Статус** | ✅ accepted |
| **Дата** | 2026-08-08 |
| **Автор** | cursor-grok |

## Контекст

Агенты петли stateless: каждая итерация — свежая сессия. Плата — повторное исследование репозитория. Величина платы до E3 не измерялась.

Handoff без карты заставляет исполнителя искать файлы Glob/Grep. Карта символов в промпте (приём Aider) обещает срезать этот налог, но сама занимает контекст и может спровоцировать лишние чтения «раз уж список дали».

Отдельно стоит blast radius для ревьюера: список вызывающих изменённых функций. Это другой потребитель и другая цена (удлиняет промпт ревью, упирается в `review_budget_usd`).

Запись ADR-006 это уже приняла (2026-08-08), но в «Альтернативах» была таблица метрик E3, а в решении — разбор blast radius. Решение не меняется; меняется запись.

## Решение

Карта символов входит в handoff исполнителя, когда задаче нужна ориентация в чужом коде: несколько разрешённых путей, новый модуль, интеграция существующих функций. Для локальной правки одного файла карту не кладём.

Карта строится на stdlib `ast` (сигнатуры + первая строка docstring, PageRank по графу вызовов). Бюджет порядка 25 строк и 500 токенов.

Blast radius (кто вызывает изменённые функции) реализован и по умолчанию выключен. Включать точечно на крупных диффах, где цена самостоятельного поиска связей высока; не как детектор — recall он не поднимает.

Не выбрано: карта всегда, карта никогда, blast radius по умолчанию.

## Альтернативы

**A. Handoff без карты (E3 вариант A).**
Отвергнут: на трёх задачах, требующих чужого кода, без карты 17 обращений к репо (из них 3 Glob), с картой 10 и 0 Glob. Фаза «где что лежит» исчезает. Исход 3/3 в обоих плечах — карта не про закрытие, а про налог исследования.

**B. Карта всегда, в том числе на правке одного файла.**
Отвергнут: на самой простой задаче E3 карта добавила чтений. Агент идёт смотреть реализации, которые иначе не открыл. Карта конкурирует за контекст с постановкой.

**C. Карта, когда задаче нужна ориентация в чужом коде.**
Принят.

**D. Blast radius (кто вызывает изменённое) включён по умолчанию для ревьюера.**
Отвергнут: recall на канарейках tenacity не вырос (вызывающий найден 2/2 без карты и 2/2 с ней). На одной задаче карта оборвала ревью по бюджету. Польза не в обнаружении, а в сокращении поиска на крупных диффах — поэтому выкл. по умолчанию, включать точечно.

## Последствия

**Плюсы**
- Налог «где что лежит» снимается без tree-sitter/ctags: stdlib `ast`, около двухсот строк.
- Та же карта годится планировщику для `paths`/`deps`.

**Минусы**
- Выигрыш измерен числом tool-call'ов, не токенами: Kimi не отдаёт usage.
- Условие включения — эвристика, не порог. На одной задаче из трёх карта навредила.

**Что осталось**
- Уточнить эвристику на большем наборе.
- Blast radius не удалять: оставлять выключенным, пока нет крупных диффов, где цена поиска связей высока.
