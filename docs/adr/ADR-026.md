
# ADR-026: Ревьюер и исполнитель — разные семейства моделей (замерено E15)

| Поле | Значение |
|------|----------|
| **Статус** | ✅ accepted |
| **Дата** | 2026-09-13 |
| **Автор** | dakh |

## Контекст

Вопрос жил с E13 как caveat by design: §3.2 петли опирался на независимость судьи, а дефолт оставлял исполнителя (kimi k3-256k, ADR-022) и ревьюера в одном семействе, предупреждая о совпадении только словами на старте прогона. E15 замерил фактор напрямую — парный пересуд без единого вызова исполнителя, два слоя. Слой 1 (2026-09-12, 9 канареек с предрегистрированными ожиданиями): ревьюер kimi k3-256k (одно семейство) recall 6/8, FPR 0/1, инъекции 2/2 → blocked; claude sonnet recall 8/8, FPR 0/1, инъекции 2/2. Разногласия — c3 и c6, обе пропущены рукой одного семейства. Слой 2 (2026-09-13, 12 замороженных brownfield-диффов E13 раунда 2): обе руки 12/12 approve, находки 0 (k3) против 3 minor (sonnet); собственный ревью петли в E13 дал те же 12 approve и 0, opus/xhigh — 12 minor. Условия замера: симметричный retry (без него k3 дала 0/9 валидных вердиктов с первой попытки) и асимметрия CLI (у sonnet форму вердикта принудил --json-schema, у kimi CLI такого флага нет — вердикт извлекался из текста потока).

## Решение

1. Ревьюер и исполнитель по умолчанию — разные семейства моделей: вердикт по умолчанию — claude sonnet при исполнителе kimi k3-256k. 2. Совпадение семейств — сознательное исключение, обязанное быть заявлено в записи прогона; поверхность принуждения — существующее предупреждение clirun.py о совпадении моделей, код петли не меняется. 3. Дешёвые модели одного семейства могут ассистировать, но вердикт им не принадлежит (контракты §5 09-дока).

## Альтернативы

Оставить дефолт одного семейства (k3 исполнитель + k3 ревьюер) — отвергнуто замером: потеря 2/8 recall на посеянных семантических багах (c3, c6 одобрены). Полный запрет совпадения семейств — отвергнуто: слой 2 показал, что на чистой работе потеря — уровня minor-шума (0 против 3 находок при полном одобрении обеими), а ассистирующие роли одного семейства полезны и дёшевы; запрет стоил бы дороже измеренного эффекта.

## Последствия

+ Гипотеза о 'общих слепых пятнах' семейства стала измерением, а не предположением; независимость судьи §3.2 подкреплена числами. + Предупреждение clirun.py остаётся рабочей поверхностью принуждения — без нового кода и новых флагов. + Согласовано с §5 09-дока: ассистенты без вердикта. − Цена разведения названа: ревью sonnet .70 + .29 = .99 за два батча (~/bin/bash.19–0.51 за дифф), цена ревьюера k3 неизмерима (квота подписки, поток цены не несёт) — сравнение полной стоимости по-прежнему одностороннее. − Разрыв валидности формы: k3 без retry дала 0/9 контракт-валидных вердиктов; retry-правило петли критично для любой будущей руки kimi-ревьюера. − n малы (9 канареек, 12 мелких диффов одного стенда); вывод — направление и величина эффекта на этом материале.
