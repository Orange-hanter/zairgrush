## Описание

Модели данных проекта: схемы сущностей, форматы хранения состояний агентов, структуры итераций и контракты данных для обмена между Исполнителем и Ревьюером.

## Структура раздела

- **Сущности** — основные объекты предметной области (Task, Iteration, AgentState, Review)
- **Контракты** — JSON-схемы для валидации данных между агентами
- **Состояния** — форматы файлов состояния для stateless-агентов
